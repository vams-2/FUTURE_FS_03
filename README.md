# 🍔 Spice Bite – Fast Food Restaurant Website

Spice Bite is a modern and responsive fast-food restaurant website designed using HTML, CSS, and JavaScript.  
The website features a premium dark-themed UI with attractive food cards, smooth layout design, and responsive sections for a better user experience.

## 🚀 Features

- Modern dark-themed UI
- Responsive design for all devices
- Hero section with attractive food background
- Interactive food menu cards
- Smooth navigation bar
- Customer reviews section
- Contact section with WhatsApp integration
- Hover animations and transitions
- Fast and lightweight website

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 🍕 Menu Categories

- Pizza
- Burgers
- Sandwiches
- Noodles
- Fries
- Cold Coffee

## 📱 Responsive Design

The website is fully responsive and works smoothly on:
- Desktop
- Tablet
- Mobile devices
